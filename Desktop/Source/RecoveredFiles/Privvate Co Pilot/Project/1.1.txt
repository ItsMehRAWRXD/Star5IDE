Installing the native helper requires two steps: compiling the helper application itself and creating the manifest file to register it with the browser. The process differs based on your operating system. 
Part 1: Develop and compile the native helper
You will create a console application that communicates with the Chrome extension by reading from its standard input (stdin) and writing to its standard output (stdout). For this example, you can use C# and Visual Studio. 
Create a C# console application. In Visual Studio, create a new Console App project named AIDesktopHelper.Host.
Add the necessary code. Replace the contents of Program.cs with the following C# code. This is a secure stub that listens for messages from the browser and echoes them back. This provides a safe, basic foundation that you can expand later.
csharp
using System;
using System.IO;
using System.Text;
using System.Text.Json;
using System.Diagnostics;

class Program
{
    static void Main(string[] args)
    {
        // For security, immediately check the extension ID passed as the first argument
        // In a real app, you would validate this against your extension's ID
        if (args.Length > 0)
        {
            // This is where you would log a valid origin, for example:
            // Debug.WriteLine($"Connected from extension: {args[0]}");
        }

        // Set I/O to binary mode for safe JSON message handling
        if (OperatingSystem.IsWindows())
        {
            __NativeMethods.SetBinaryMode(Console.OpenStandardInput().Handle);
            __NativeMethods.SetBinaryMode(Console.OpenStandardOutput().Handle);
        }

        while (true)
        {
            try
            {
                // Read message length (4 bytes)
                byte[] lengthBytes = new byte[4];
                if (Console.OpenStandardInput().Read(lengthBytes, 0, 4) != 4)
                {
                    return; // Disconnected or error
                }
                int length = BitConverter.ToInt32(lengthBytes, 0);

                // Read the JSON message
                byte[] messageBytes = new byte[length];
                if (Console.OpenStandardInput().Read(messageBytes, 0, length) != length)
                {
                    return; // Disconnected or error
                }
                string messageString = Encoding.UTF8.GetString(messageBytes);

                // Process the message securely
                JsonDocument message = JsonDocument.Parse(messageString);
                var action = message.RootElement.GetProperty("action").GetString();

                // Securely process the command (e.g., call a whitelisted function)
                string responseMessage = ProcessSecureCommand(action, message);

                // Echo a secure response
                byte[] responseBytes = Encoding.UTF8.GetBytes(responseMessage);
                byte[] responseLengthBytes = BitConverter.GetBytes(responseBytes.Length);
                Console.OpenStandardOutput().Write(responseLengthBytes, 0, 4);
                Console.OpenStandardOutput().Write(responseBytes, 0, responseBytes.Length);
                Console.OpenStandardOutput().Flush();

            }
            catch (Exception ex)
            {
                // For debugging, write errors to stderr
                Console.Error.WriteLine($"Error in native host: {ex.Message}");
                return;
            }
        }
    }

    // IMPORTANT: Implement this function with strict input validation and a whitelist
    static string ProcessSecureCommand(string action, JsonDocument message)
    {
        if (action == "sayHello")
        {
            return JsonSerializer.Serialize(new { response = "Hello from the native host!" });
        }
        // Add other whitelisted commands here
        return JsonSerializer.Serialize(new { response = "Error: Invalid or unauthorized command." });
    }

    // Internal methods for setting binary mode on Windows
    private static class __NativeMethods
    {
        private const int _setmode = 20480;
        private const int _O_BINARY = 0x8000;

        [System.Runtime.InteropServices.DllImport("msvcrt.dll", CallingConvention = System.Runtime.InteropServices.CallingConvention.Cdecl)]
        private static extern int _setmode(int fd, int mode);

        internal static void SetBinaryMode(IntPtr handle)
        {
            _setmode(handle.ToInt32(), _O_BINARY);
        }
    }
}

Compile the application.
Open the Build menu in Visual Studio and select Build Solution.
The compiled executable (.exe) will be located in the bin/Debug/net8.0 directory within your project folder. 
Part 2: Create and install the native manifest file
The browser needs to be told where to find your native helper application. This is done with a JSON manifest file and a registry entry on Windows, or by placing it in a specific location on macOS. 
Create the manifest file
Create a new JSON file in your project folder (e.g., native-host-manifest.json).
Edit the contents. Be sure to replace <your-extension-id> with the actual ID of your extension after you have loaded it in Developer Mode. The path should point to the compiled executable you built in the previous step.
json
{
  "name": "com.my_company.my_application",
  "description": "Custom desktop AI helper",
  "path": "C:\\path\\to\\your\\AIDesktopHelper.Host.exe",
  "type": "stdio",
  "allowed_origins": [
    "chrome-extension://<your-extension-id>/"
  ]
}
Use code with caution.

Install the manifest (Windows)
Open the Start Menu and search for Command Prompt. Right-click it and select Run as administrator.
Use the REG ADD command to create the necessary registry key. Replace <path-to-manifest.json> and <your-application-name> with your specific values.
batch
REG ADD "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.my_company.my_application" /ve /t REG_SZ /d "<path-to-manifest.json>" /f
Use code with caution.

 
Install the manifest (macOS)
Open Terminal.
Navigate to the Chrome Native Messaging hosts directory. For the current user, the directory is ~/Library/Application Support/Google/Chrome/NativeMessagingHosts/.
Copy the manifest file into that directory.
sh
cp /path/to/your/native-host-manifest.json ~/Library/Application\ Support/Google/Chrome/NativeMessagingHosts/com.my_company.my_application.json
Use code with caution.

 
Part 3: Test the communication
Update your background.js in the Chrome extension with the following code snippet to test the connection.
javascript
// In background.js
function sendNativeMessage() {
  // Connects to the host using the name defined in the manifest file
  let port = chrome.runtime.connectNative('com.my_company.my_application');

  port.onMessage.addListener((message) => {
    console.log("Received from native host:", message);
  });

  port.onDisconnect.addListener(() => {
    if (chrome.runtime.lastError) {
      console.error("Disconnected:", chrome.runtime.lastError.message);
    }
  });

  port.postMessage({ action: "sayHello" });
}

// Call this function from your popup or as a test
sendNativeMessage();
Use code with caution.

Reload your extension on the chrome://extensions page.
Open the extension's console and check for the Received from native host: message. If successful, you are ready to expand your native host's functionality.
