1. Chrome Extension's manifest.json
This is the main configuration file for your browser extension. It lists permissions, scripts, and what the extension can do. You should have a nativeMessaging permission declared here. 
Example:
json
{
  "manifest_version": 3,
  "name": "Secure AI Desktop Helper",
  "version": "2.0",
  "permissions": [
    "activeTab",
    "scripting",
    "storage",
    "nativeMessaging"
  ],
  "host_permissions": [
    "https://api.openai.com/"
  ],
  // ... other extension settings
}
Use code with caution.

2. Native Messaging Host Manifest (native-host-manifest.json)
This file is used to register your native application with the browser. It tells the browser where to find and how to communicate with your native helper executable. This file does not go in your extension's project folder. It gets installed on your computer's file system, and its location is registered in the system registry (on Windows) or in a specific user directory (on macOS and Linux). 
Example:
json
{
  "name": "com.my_company.my_application",
  "description": "Custom desktop AI helper",
  "path": "C:\\path\\to\\your\\AIDesktopHelper.Host.exe",
  "type": "stdio",
  "allowed_origins": [
    "chrome-extension://<your-extension-id>/"
  ]
}
Use code with caution.

How to use the native messaging host manifest
Do not rename your extension's manifest.json file.
Create a new file with a different name, such as native-host-manifest.json, and place it somewhere on your system.
Update the path in the native-host-manifest.json to the correct location of your compiled C# executable.
Install it by adding the registry key (on Windows) or copying it to the correct directory (on macOS/Linux), as instructed in the previous response.
