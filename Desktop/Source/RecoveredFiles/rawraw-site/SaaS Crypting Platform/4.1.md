# Crypting SaaS Platform Documentation

## Quick Start
1. Run `./setup.sh` to deploy with Docker
2. Access the web interface at http://localhost:3000
3. Register first user (automatically becomes admin)

## API Usage
```bash
curl -X POST http://localhost:5000/api/v1/crypt \
  -H "Authorization: Bearer <JWT_TOKEN>" \
  -F "file=@payload.exe" \
  -F "config={\"obfuscationLevel\": \"high\"}"
